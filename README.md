# kb — ЗНАНИЯ ДОМА

> заведён 2026-11-16 по явной команде Хозяина; канон §4: место для знаний — kb
> 1 смысл = 1 репо: это хранилище ЗНАНИЙ (тексты, досье, гайды), не кода и не адресов

## Что здесь живёт

| раздел | смысл |
|---|---|
| `canon/` | канон-тексты и их редакции (ссылки на оригиналы обязательны) |
| `guides/` | гайды и регламенты: как делать повторяемые операции дома |
| `dossier/` | досье и разборы: инциденты, аудит-выводы, решения владельца |

## Правила

- Знания имеют АДРЕС и ДАТУ: файл знает, откуда взят (ссылка/SHA) и когда положен.
- Оригинал знания не дублируется: если канон живёт в `edinyy-svod` — здесь только указатель.
- Изменения канона — только по процедуре канона (статья 97), не тихой правкой.
